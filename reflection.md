## what was generated
Copilot generated the script for the data cleaning and conversion as well as any comments in the code. It was prompted to take the data from the specific raw data file. It was then prompted to put that data into the cleaned data csv, or sales_data_clean.csv.

## What I modified
I modified some of the formatting of the repository and fixed some of the file formatting, as the data was being pulled from the wrong place.

## What I Learned
I learned that while copilor is very useful for helping me code, it is not perfect. It can only do what it is prompted to do, and even then it cannot do it perfectly. It is not something to make do the work for you. When I tried to just make it code everything all at once in the first code, it was completely unable because it was not given a specific enough prompt. even when I did format the folders and files, it still was not enough to just throw a prompt at it. It had to know EXACTLY what file to pull from and EXACTLY where to put it.
